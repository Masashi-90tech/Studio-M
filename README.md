# Studio M

> DIYのための、設計・解析・製作がつながる工房

「このブラケットは5kgに耐える？」「このケースは何℃になる？」。
DIY で何かを作るとき、知りたいのはたいていこうした問いです。Studio M は、その問いから完成した部品までを一本の流れで案内するツールです。

FreeCAD は何でもできる道具箱です。Studio M は道具箱を渡す代わりに、**目的から入る体験**を用意します。

## 設計思想

**エンジンは借りる、体験は自作。**

流体・熱・強度の計算には、実績のあるオープンソースのソルバーを使います。その上の「問いを立てる」「条件を置く」「結果を読む」部分は Studio M が自前で作り、分かりやすい日本語の体験にします。

## 現在の機能（Studio M Lite / 段階0）

ブラウザで動く 2D の解析環境です。

- **形状描画**: 矩形・円・多角形・フリーハンドで断面を描く
- **役割の割り当て**: 物体、発熱体、穴、温度固定、支持、荷重
- **材料**: PLA, PETG, ABS, A6061, A5052, SS400, SUS304, C1100, FR-4, 空気, 水
- **解析**
  - 流れ: 格子ボルツマン法（D2Q9 + Smagorinsky）。カルマン渦列、抗力・揚力を確認。「温度も計算する（風で冷やす）」をオンにすると、同じ格子で温度の移流拡散も解き（共役伝熱）、ファンの風でヒートシンクや部品が何℃になるかを調べられる（PC の本計算 OpenFOAM は流れだけ）
  - 熱: 定常熱伝導（有限体積法）。周囲への対流を含む
  - 強度: 2D 平面応力の有限要素法（Q4 要素）。von Mises 応力と安全率
  - 対流拡散: 「@CFDbyHand」の Excel 例「一様流中の四角柱まわり」を再現
- **KiCad 基板の熱**: 「ファイル」→「KiCad基板を開く」（または作図エリアへ .kicad_pcb をドロップ）で、基板の形・銅箔・部品の位置を取り込み、部品ごとの発熱（ライブラリの目安値を書き換え可）から基板の温度を解く。手元に基板がなければ「サンプル基板で試す」。ファイルはブラウザの中だけで処理し、通信しない
- **3D モデルの断面**: 「ファイル」→「3Dモデルを開く（STL・OBJ）」（または作図エリアへ .stl / .obj をドロップ）で、Blender や CAD のモデルを 3D で見ながら切る面（X / Y / Z と位置）を選び、その断面を外形と穴の 2D の形にして、流れ・熱・強度・電磁波の解析にかける。穴のあるモデル（水密でない）は注意を出し、重なった頂点などは自動で直す。手元にモデルがなければ「サンプル（穴のあいた板）で試す」。ファイルはブラウザの中だけで処理し、通信しない
- **部品ごとの温度**: 熱の結果の下に、部品ごとの最高温度・上限温度との差を表で出す。判定カードは一番熱い部品を名指しし、冷却（自然放置・ファン）を切り替えて温度の下がり方を比べられる
- **数学の窓**（学習機能をオンにすると出ます）: 判定カードの下に「この答えの式」を出し、今の数値を代入して見せる。スライダーで変数を動かすと結果と一言（例: 長さ 2 倍 → たわみ 8 倍）が変わる
- **学習機能の切り替え**: 数学の窓と学ぶモードは、ヘッダーの設定（⚙）の「学習機能を表示する」で出し入れする。既定はオフ（画面がすっきり）で、オフのあいだは学習用の部品を読み込まない。設定はブラウザごとに保存
- **学ぶモード**（学習機能をオンにすると出ます）: ヘッダーの「学ぶ」から、理論 → やってみる → 確認問題 → 実践の 11 レッスン（中学・高校・大学の順）。プリセットを開いて、操作しながら進められる。進み具合はブラウザに保存
- **Excel 出力**
  - 結果ブック: 条件・形状・材料、温度や応力のヒートマップ（条件付き書式）、履歴
  - 数式ブック: Excel 自身が反復計算で対流拡散を解く（動画と同じ考え方）

## Studio M Engine（PC で本計算）

Lite はブラウザの中の簡易な計算です。もっと確かな答えが欲しいときは、この PC の上で **Studio M Engine** を動かし、
**CalculiX**（強度）や **OpenFOAM**（流れ）で「本計算」できます。結果は Lite の結果と切り替えたり、代表値を並べて比べたりできます。

```bash
npm run engine     # エンジンを起動（Node.js 22 以上）。画面に URL と合言葉が出る
```

1. ダウンロードした HTML（または `npm run dev` の開発版）で Studio M を開く
2. ⚙ 設定 →「PCのエンジン」に URL と合言葉を貼り付けて「接続を確認」
3. 強度・流れのタブで「本計算で解く」→ 進み具合 → 完了後に「Lite ⇄ 本計算」と比較表

- 解析ソフトは別プロセスとして呼ぶだけで、Studio M には同梱しません（GPL）。入れ方（Ubuntu / Docker / Windows の WSL / macOS）は [docs/ENGINE.md](docs/ENGINE.md)
- **安全**: エンジンは `127.0.0.1` だけで待ち受け、起動のたびに作る合言葉がないと答えません。画面から受け取るのは形と条件の JSON だけで、ファイルのパスや命令は受け取りません
- claude.ai に公開したページ（Artifact）からは PC のエンジンに届きません。ダウンロードした HTML か開発版で使ってください

## 精度についての注意

- 結果は**傾向と比較**のためのものです。絶対値として設計判断に使わないでください。
- 2D の近似です。奥行き方向には一定の厚さの板として扱います。
- 3D プリントの部品は Z 方向（積層方向）の強度が弱くなります。
- 安全に関わる用途では、必ず専門のツールで検証してください。

## はじめかた

Node.js と npm が必要です。

```bash
npm install       # 依存関係をインストール
npm run dev       # 開発サーバーを起動
npm test          # テストを実行（vitest）
npm run build     # 型チェックのあと、dist/ に単一の HTML ファイルを出力
npm run engine    # PC のエンジン（Studio M Engine）を起動。本計算に使う
npm run check     # 型チェック + テスト + ライセンス確認
```

`npm run build` の結果は、外部ファイルなしで単体で動く HTML です。

## 仕組み（要点）

- **座標と格子**: 単位はメートル。原点は解析領域の左下。セルは正方形で、格子の幅は `domain.width / nx` で決まります。
- **共通データモデル**: 描画・ソルバー・Excel 出力は、すべて `src/core/types.ts` の型だけを介してやり取りします。
- **少しずつ計算する**: ソルバーは `step(budgetMs)` で時間を区切って計算を進めます。画面は計算の合間に結果を描くため、固まらずに進み具合を見られます。
- **形状の重ね順**: 形状は配列の順に適用され、後のものが前のものを上書きします。穴あけは、それより前に置かれた物体を削ります。

## ディレクトリ構成

```
src/
├── core/      共通データモデル（types.ts）、材料（materials.ts）、格子化（raster.ts）、初期値（project.ts）
├── solvers/   流れ・熱・強度・対流拡散のソルバーと、その登録（index.ts）
├── export/    Excel 出力
engine/        Studio M Engine（PC 上の Node.js サーバー）: server/（HTTP・ジョブ・実行）、adapters/（CalculiX・OpenFOAM の変換役）
├── workbench/ 解析 1 つ分のまとめ（ソルバー・パネル・判定・プリセット・数学の窓）と登録表
├── pcb/       KiCad 基板の取り込み（読み取り・部品ライブラリ・熱プロジェクトの組み立て・ダイアログ）
├── mesh3d/    3D モデル（STL・OBJ）の取り込み（読み取り・メッシュの整理・断面・3D ビューア・ダイアログ）
├── learn/     数学の窓（式の提供者・部品）、レッスン、進み具合
├── ui/        エディタ、パネル、描画、プリセット、数学の窓のカード、「学ぶ」ドロワー
└── main.ts    エントリーポイント
```
