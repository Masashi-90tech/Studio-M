# Studio M ロードマップ

## ビジョン

DIY のための、設計・解析・製作がつながる工房。
「このブラケットは壊れない？」「このケースは何℃になる？」「電波は通る？」という問いから、
完成したモノまでを 1 つのデータでつなぐ。使いながら、その裏にある数学と物理も学べる。

まずは自分用。自分が実際に作りたいモノで使い、詰まったところから育てる。

## 原則

1. **エンジンは借りる、体験は自作。** ソルバーや形状カーネルは実績のある OSS を使い、画面・操作・判定・学びを自作する
2. **データは 1 つ。** 形状・材料・条件・結果・部品・手順書に共通の ID を振り、すべてのワークベンチで共有する
3. **差し替えられるようにする。** 外部エンジンとの間には変換層を挟み、バージョンを固定する。止まったエンジンは乗り換える
4. **かんたん → プロ。** 目的と日常の言葉から入り、必要な人だけ細かい設定に進める。設定は「自動（理由つき）⇄ 手動」
5. **答えには根拠を。** 判定には、その裏にある式と数値を添える。新しい解析には、理論値やベンチマークとの照合テストを付ける
6. **ライセンスを守る。** Studio M 本体は MIT。GPL / AGPL のツールは組み込まず、別プロセスとして呼び出す
7. **モジュールの約束を守る。** モジュール同士は契約の型だけでやり取りし、引数はオプションオブジェクト、項目の追加は省略可能にする。重いモジュールは遅延 import する（詳しくは `CLAUDE.md`）
8. **OSS は台帳で管理する。** 使う・使う予定・参考にした OSS をすべて `docs/oss-ledger.json` に記録し、`npm run licenses` で確認する（詳しくは `docs/OSS.md`）

## 強度の拡張（v0.4 以降、順次）

- 壊れ始める荷重: 線形解析なので「壊れ始める荷重 ≒ 今の荷重 × 安全率」。場所付きで示す（例: 約 23 kg で内角から）
- 材料ごとの壊れ方: 金属はミーゼス応力、PLA・ガラスなど脆いものは最大主応力、3D プリントは積層方向で強さを変える（異方性）
- 座屈（固有値解析）、疲労（S-N 曲線、計算書向き）
- 実験記録: 実物の試験片を吊り秤などで壊した結果を記録し、材料の値を自分のプリンター用に補正する
- 壊れていく過程（将来の目標）。段階を分けて進める
  1. 2D の塑性（増分解析）と大変形を Lite で
  2. 2D のひびの進展を Lite でアニメーション表示（位相場法かペリダイナミクスを自作）
  3. 本格エンジン: CalculiX（塑性・大変形・接触）、Code_Aster（非線形・X-FEM）、FEniCSx / MOOSE（位相場法）、OpenRadioss（衝撃・破断、AGPL のため別プロセス）。ライセンスは採用時に確認して台帳へ
  4. 破壊靭性などは実験記録から逆算して、自分のプリンター・材料に合わせる
  - 3D プリント品の積層間のはがれも扱う。狙いは「何 kg で壊れるかを当てる」より「どこから、どの順に壊れるかを見て形を直す」こと

## 長期構想（v1.0 以降）

### プロセス（P&ID）ワークベンチ

- P&ID エディタ: 機器・配管・弁・計装を ISA-5.1 の記号で描き、タグ番号付きのグラフとして持つ。交換形式は DEXPI を検討
- 配管網の流れと圧力（1D ネットワーク計算）
- 動的シミュレーション: 液位、反応槽の温度、弁の開閉（常微分方程式。将来は Modelica / OpenModelica）
- 熱力学・分離: 物性とフラッシュ計算（CoolProp、thermo、Cantera、DWSIM）
- 詳細が必要な機器は CFD ワークベンチへ渡す。最終的には画面の中に大きなプラントを建ててシミュレーションする

### 計算書ワークベンチ

- 配管の必要肉厚（ASME B31.3 など）
- フランジ・ガスケット: 締付力 → 面圧 → 漏れ始める内圧（ASME のガスケット係数、EN 1591-1）、締付トルク
- 漏れ量（液体、ガスのチョーク流れ）
- 腐食速度 → 減肉 → 強度の再計算 → 点検予定（RBI の考え方）
- 簡易反応モデル（アレニウス式、CSTR / PFR）。詳細は Cantera
- 注意: 高圧ガス・圧力容器は法規制の対象になりうる。計算は検討用

### 製作管理

- 手順書: 設計データから印刷設定・組立順・締付トルク・配線を自動生成
- 部品・在庫: KiCad の BOM と手持ち在庫を突き合わせる（InvenTree などと連携）
- 保全管理（CMMS）: 3D プリンター・CNC の稼働時間、消耗品、点検周期、故障履歴

## 数学の学び直し

Studio M の中身はそのまま数学の教材になる。v0.3 以降、各機能に「数学の窓」を付けていく。

| 数学 | Studio M のどこにあるか |
|---|---|
| 比例・一次関数 | オームの法則、フックの法則、発熱量と温度上昇 |
| 三平方・ベクトル | 力の合成、流れの速さ、荷重の向き |
| 三角関数 | 電波、翼の迎角、斜めに入射するレーダー |
| 指数・対数 | dB 表示、反応速度（アレニウス式）、腐食 |
| 微分 | 温度の傾き → 熱の流れ、変位の傾き → ひずみ → 応力 |
| 積分 | 圧力の足し合わせ → 抗力・揚力、質量 |
| 数列・収束 | 反復計算の残差 |
| 連立方程式・行列 | 強度解析（FEM）の K·u = f |
| 偏微分方程式 | 熱（ラプラス方程式）、電波（波動方程式）、流れ（ナビエ–ストークス方程式） |
| 複素数・フーリエ | レドームの透過率、渦の周期（ストローハル数） |
| 数値解析 | Excel 数式ブック（微分方程式をセルの計算に分解する） |
