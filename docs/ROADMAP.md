# Studio M ロードマップ

Studio M は、手軽な 2D 解析から始めて、3D・製作・回路まで一直線につながる工房へ段階的に広げていきます。各段階は、前の段階で作った体験を壊さずに、エンジンを足す・差し替えることを基本にします。

## 段階

### 段階0: Studio M Lite（ブラウザ・2D）— 現在

- 流れ・熱・強度・対流拡散を、ブラウザ上で実行する
- Excel 出力（結果ブック・数式ブック）
- 狙い: 「問いを立てて、すぐ結果が見える」体験を確かめる

### 段階1: 本格エンジン接続

- PC 上の Docker で本格ソルバーを動かす
  - OpenFOAM: 流れと熱（共役熱伝達を含む）。ケースの制御は foamlib で行う
  - CalculiX: 強度（FEM）
  - Elmer: 熱とマルチフィジックス

### 段階2: 3D・CAD 連携

- 形状カーネル: OpenCASCADE（ブラウザでは opencascade.js / replicad、Python では build123d / CadQuery）
- STEP / STL の読み込み
- メッシング: gmsh
- 3D ビューア

### 段階3: 製作連携

- 3D プリンター: STL 出力、スライサーへの受け渡し。材料と印刷プロファイル（インフィル、積層方向による強度の違い）を扱う
- CNC: FreeCAD CAM による加工
- 製作可否チェック（printability）

### 段階4: 回路連携

- KiCad: 基板の STEP と発熱源を取り込み、基板まわりの熱を解析する
- ngspice: 回路のシミュレーション

### 段階5: 統合と高度化

- パラメトリック 3D CAD（スケッチの拘束、フィーチャー履歴）
- AI アシスタント（自然言語での解析設定、設計の助言）
- 設計案の比較と履歴
- 長期目標: 製作者が実際に必要とする部品の範囲で、CATIA 級の機能に近づける

### AI 連携（段階1から順次）

AI が形を提案し、Studio M が物理で確かめ、AI が直す、というループを作る。

1. CLI: `studio-m run project.json --analysis stress --excel out.xlsx` のように画面なしで計算する
2. MCP サーバー: 「形状の追加」「材料の変更」「解析の実行」「結果の取得」「Excel 出力」をツールとして公開し、Claude などの AI から会話で操作できるようにする
3. AI CAD の取り込み: AI が作った STEP/STL、CadQuery・build123d のコードを読み込む
4. アプリ内アシスタント: 結果を見ながら原因や対策を相談する
5. 自動最適化: 案 → 解析 → 改善の繰り返し（個人版ジェネレーティブデザイン）

プロジェクトは JSON（スキーマを公開する）、形状は STEP/STL/glTF と標準形式に寄せ、特定の AI に縛られないようにする。

### 段階6: 製作管理

- 手順書: 設計データから印刷設定・組立順・締付トルク・配線などを自動生成（PDF/Excel）
- 部品・在庫: KiCad の BOM を取り込み、手持ち在庫と突き合わせて不足部品と購入先を出す（InvenTree などと連携）
- 保全管理（CMMS）: 3D プリンター・CNC の稼働時間、消耗品交換、点検周期、故障履歴
- 前提: 形状・材料・部品・機械・手順書のすべてに共通の ID を振り、互いにたどれるデータ設計にする

## 構想: プロセス（P&ID）ワークベンチ

プラントのように P&ID を描き、そのまま流れ・温度・分離をシミュレーションする。

- P&ID エディタ: 機器・配管・弁・計装を ISA-5.1 の記号で描き、タグ番号（P-101、TI-301 など）付きのグラフとして持つ。交換形式は DEXPI を検討
- 配管網の流れ: どの配管にどれだけ流れるか、圧力分布（EPANET 的な 1D ネットワーク計算）
- 動的シミュレーション: 槽の液位・反応槽の温度・弁の開閉の時間変化（常微分方程式。将来は Modelica / OpenModelica）
- 熱力学・分離: 物性とフラッシュ計算で気液分離・ガス回収（CoolProp、thermo、Cantera、DWSIM）
- 詳細が必要な機器（撹拌槽の混合など）は CFD ワークベンチへ渡す

## 構想: 計算書ワークベンチ

シミュレーションより軽い「規格に沿った計算」を、Excel の計算書として出す。

- 配管の必要肉厚（ASME B31.3 など）
- フランジ・ガスケット: 締付力 → ガスケット面圧 → 漏れ始める内圧（ASME のガスケット係数、EN 1591-1）、締付トルク
- 漏れ量: 隙間・小孔からの漏れ（液体、ガスのチョーク流れ）
- 腐食: 腐食速度（耐薬品性表、CO₂ 腐食の経験式）→ 減肉 → 強度の再計算 → 点検予定を保全管理へ（RBI の考え方）
- 反応: アレニウス式による CSTR/PFR の簡易反応モデル。詳細な反応機構は Cantera
- 注意: 高圧ガス・圧力容器は法規制の対象になりうる。計算は検討用で、実設備には有資格者の設計・検査が必要
