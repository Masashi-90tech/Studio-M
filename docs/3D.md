# 3D モデルと 3D 解析（v0.6）

Blender や CAD で作った 3D モデル（STL・OBJ）を Studio M で使う方法です。使い方は 2 通りあります。

| 使い方 | 中身 | 向く問い |
|---|---|---|
| **断面を 2D で解く** | 3D モデルを平面で切り、その断面を 2D の形にして、今までの流れ・熱・強度・電磁波にかける | 「この断面で、流れや応力はどうなる？」をすぐ見る |
| **3D のまま解く** | 3D モデルをそのまま、小さな立方体（ボクセル）に分けて解く。熱と流れに対応 | 「部品のどこが何℃になる？」「風がどう回り込む？」を 3D で見る |

どちらもブラウザの中だけで計算し、ファイルを外に送りません。

## 試し方

1. 「ファイル ▾」→「3Dモデルを開く（STL・OBJ）」を押す（作図エリアに .stl / .obj をドロップしてもよい）。
   手元にモデルがなければ「サンプル（穴のあいた板）で試す」
2. ダイアログの左に 3D、右に断面が出る。ドラッグで回転、ホイールで拡大。
   **長さの単位**（mm / m / inch）を合わせる。STL・OBJ には単位が入っていないので、多くは mm
3. ここから 2 通りに分かれる
   - **断面を 2D で解く**: X / Y / Z とスライダーで切る位置を選び、解析と材料・厚さを選んで「取り込む」
   - **3D のまま解く**: 「3D のまま解析する」。全画面の 3D 解析の画面が開く（✕ か Esc で 2D の画面に戻る）

閉じていない（穴のあいた）モデルは注意が出ます。重なった頂点やつぶれた三角形は自動で直します。
穴は Blender の「3D プリント」ツールボックスの「チェック」で場所を探し、「Make Manifold」などで埋めてから書き出し直してください。

## 3D の熱

部品の中の温度（定常の熱伝導）を解きます。

1. 画面の上で「熱」を選ぶ
2. **材料**、**周囲の温度**、**まわりの冷え方**（自然放置 h = 8・弱い風 20・ファン 40・強いファン 80・数値）を選ぶ
3. **面の条件**を置く: 3D の図で面をクリックして選び（Shift / Ctrl で足す。つながっていて向きがほぼ同じ三角形がまとめて選ばれる）、
   - **発熱**（W）: 選んだ面から熱を入れる。部品が面に載っている、など
   - **温度を固定**（°C）: 冷えた板に押し当てている面、など
   - **ファンが当たる**（h）: その面だけ熱の逃げやすさを変える
   - **断熱**: その面から熱を逃がさない
   部品全体が均等に発熱するときは「部品全体の発熱」に W を入れる
4. **計算の細かさ**（粗い 5 万 / 標準 30 万 / 細かい 100 万セル）を選んで「計算する」
5. 表面の温度の色と凡例、X / Y / Z の断面、判定（材料の耐熱の目安との余裕）、条件ごとの最高・平均温度が出る

条件を置いていない面は、まわりの冷え方の h で周囲へ熱を逃がします。条件や設定を変えると、前の結果は「古い結果」になります。

## 3D の流れ

部品を「風洞」（直方体の空間）に置いて一様な風を当て、まわりの流れと部品にかかる力を解きます。

1. 画面の上で「流れ」を選ぶ
2. **流体**（空気・水）、**風の向き**（±X・±Y・±Z）、**速さ**（そよ風 1・扇風機 3・自転車 6・車 28 m/s・数値）、
   **まわり**（開けた場所 = 風洞の壁の影響なし / ダクトの中 = 壁にも摩擦）、**計算の細かさ**（粗い 8 万 / 標準 25 万 / 細かい 60 万セル）を選ぶ
3. 「計算する」。流れは時間とともに変わるので、**止めるまで進み続けます**（一時停止・再開・最初から）
4. 表示: 風洞の枠と風の矢印、部品の表面の色（圧力 / 流速）、断面の流速・圧力、3D の流線（上流から 12 × 12 本。速さで色分け）
5. 結果: レイノルズ数、抗力、抗力係数 Cd、揚力、経過時間、判定（なめらか / 渦ができる / 乱れた流れ）

風洞の大きさは、部品の幅 D（風に垂直な向きの寸法の大きい方）に対して、上流 1.5D・下流 4D・横 1.5D です。
風が部品を 3 回ほど通り抜けるまでは、力の値が落ち着きません（そのあいだは、画面に通り抜けた回数と「落ち着くまでしばらく変わります」という一言が出ます）。

## 精度（テストで照合した結果）

| 解析 | 照合 | 結果 |
|---|---|---|
| 3D の熱 | 1 次元の棒（片端を固定温度、もう片端から熱を入れる） | 手計算と 2% 以内 |
| 3D の熱 | 熱収支（入れた熱 = 逃げた熱） | 1% 以内 |
| 3D の熱 | 球を全面で冷やす（表面積の補正の確認） | 集中定数の式と 0.02% 以内 |
| 3D の熱 | ピンフィン（根元を固定温度、側面と先端が対流）の放熱量 | フィンの式と 0.2% 以内 |
| 3D の熱 | ヒートシンクの例（アルミ、底面に 5 W、自然放置） | 最高 89.4 °C、手計算の温度上昇 64 K と一致 |
| 3D の流れ | 正方形ダクトの発達した流れ（中心 / 平均の速さ） | 2.053（解析解 2.096、−2.1%） |
| 3D の流れ | 左右対称の部品の揚力 | 抗力の 2% 未満（ほぼ 0） |
| 3D の流れ | 球の抗力係数（Re = 20〜40、Schiller–Naumann の式） | 部品の幅 8 セルで約 1.4 倍、12 セル以上で約 1.2 倍 |

- **熱**は、表面が階段状になるぶん（球で表面積が約 1.55 倍）を、元の形の面積に合わせて補正しています
- **流れ**は、流れのようす（渦・流線・圧力の分布）の傾向を見るのに向きます。**抗力の数字は 2〜4 割大きめ**に出ます。
  部品の幅が 12 セル未満のときは、画面にその注意が出ます

## 限界と注意

- **熱と流れだけ**です。3D の強度は PC のエンジン（CalculiX）で行う予定です
- 曲面は階段状に近づけます。体積が元の形から 10% 以上ずれると注意が出ます。細い部分（セル 1 つより薄い）は消えることがあります
- 3D の流れは、まだ温度を解きません（2D の流れでは「温度も計算する（風で冷やす）」が使えます）
- **速さ**: 3D の流れは重く、25 万セルで、Node での計測は 1 秒に約 27 ステップです。
  作業用の環境（GPU のないブラウザ）では、3D の描き直しに時間を取られて 1 秒に約 5 ステップでした。
  計算と描画が同じ処理の流れを取り合っているためで、計算を別のスレッド（Web Worker）に移す予定です
- 3D 解析の画面を開いているあいだは、裏の 2D の計算を止めます（閉じると元に戻る）
- 3D の検討（形・材料・面の条件）をファイルに保存する仕組み（`src/core/study3d-io.ts`）はありますが、画面の「保存」「開く」ボタンはまだありません
- STEP・glTF は読めません。STL か OBJ に書き出してください
- 結果は傾向と比較のためのものです。安全に関わる用途では、専門のツールで確かめてください

## 仕組み（開発者向け）

```
3D モデル（STL・OBJ）
  └─ src/mesh3d/       読み取り・メッシュの整理・断面・3D ビューア・取り込みダイアログ
        ├─ 断面 → Project（2D）→ 今までの 2D の画面
        └─「3D のまま解析する」→ Study3D（onAnalyze3D で渡す。mesh3d は sim3d を知らない）
              └─ src/sim3d/   3D 解析の画面（面の選択・条件・設定・結果の表示・流線）
                    ├─ src/solvers/heat3d.ts   3D の熱（ボクセル、共役勾配法）     ← 遅延 import
                    └─ src/solvers/flow3d.ts   3D の流れ（D3Q19 の格子ボルツマン法）← 遅延 import
```

- **契約**: `src/core/types.ts` の末尾「3D 解析」の型（`Study3D`・`Region3D`・`Flow3DSettings`・`ResultSet3D`・`Solver3D`）。
  条件は、画面で選んだ面（三角形の番号）に置く
- **同じ格子**: `src/core/grid3d.ts` の `studyGrid` が格子を決めます（流れのときは風洞全体）。
  Lite も、将来の PC のエンジン（CalculiX・OpenFOAM）も、結果をこの格子に載せて返すので、3D の画面のまま並べて比べられます
- **ボクセル化**: `src/core/voxelize.ts`（部品の中のセル、外に出ている面とそれに近い三角形、表面積の補正）
- **保存・通信の形**: `src/core/study3d-io.ts`（型付き配列を base64 にした JSON。ファイルの種類は `studio-m-study3d`）
- 層の決まりは `CLAUDE.md` の表（`src/mesh3d`・`src/sim3d` の行）。`src/mesh3d/layers.test.ts`・`src/sim3d/layers.test.ts`・
  `src/workbench/shell.test.ts` が確かめます
